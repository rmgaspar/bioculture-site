Ligação ao GitHub

Para aprovar ou recusar é preciso uma chave do GitHub só para este repositório. Fica guardada apenas neste navegador.

  1. Abre a criação de chaves.
  2. Em Repository access escolhe só bioculture-site.
  3. Em Permissions → Repository permissions põe Actions: Read and write (nada mais).
  4. Copia a chave gerada e cola-a aqui.
