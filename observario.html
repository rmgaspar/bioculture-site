bioCulture Observatório de Impacto

Observatório Ambiental (2004 - 2024)

Análise comparativa de dados estatísticos oficiais dos últimos 20 anos. Este observatório cruza dados de incêndios, produção agrícola, pecuária, temperatura e consumo de água para monitorizar a regeneração e o impacto no território português.

Fontes de Dados

  • Incêndios: ICNF (Área Ardida em Hectares)
  • Produção: Banco Mundial / INE (Índices de Produção)
  • Clima: IPMA (Temperatura Média Anual)
  • Água: ERSAR / PORDATA (Consumo m3/pessoa)
